# SongPilot Store Release Checklist

This checklist complements, but does not replace, the current requirements in Apple Developer, App Store Connect, Google Play Console and applicable law.

## Before building

- [ ] Enroll in Apple Developer Program and Google Play Console.
- [ ] Decide whether the seller/developer is an individual or legal entity; complete tax, banking and verification details as needed.
- [ ] Set final Android application ID and iOS bundle identifier.
- [ ] Generate `ios/` and `android/` under `flutter_app/`, configure app names, version/build numbers, signing, permission strings and production settings, then commit the configuration that does not contain secrets.
- [ ] Add an iOS microphone usage description and Android `RECORD_AUDIO` permission, then test permission denial and recovery.
- [ ] Run `flutter pub get` and `dart run flutter_launcher_icons` from `flutter_app/`; review the generated Android/iOS icons on physical devices.

## Authentication and accounts

- [ ] Test email/password sign-up, sign-in, sign-out, session restoration and password recovery on physical iOS and Android devices.
- [ ] If Google Sign-In is offered on iOS, implement and configure Sign in with Apple unless a documented Apple exception applies.
- [ ] Test account deletion end to end: request, authorised server-side processing, removal of Auth identity, profiles, songs, sections, collaboration records and storage objects, and user notification.
- [ ] Put working test-account credentials and any special reviewer instructions in App Store Connect Review Notes.

## Privacy and safety

- [ ] Replace every `[TODO]` in `PRIVACY_POLICY.md`; obtain appropriate legal review and publish it on a public HTTPS URL.
- [ ] Link the public privacy-policy URL in the app, App Store Connect and Google Play Console.
- [ ] Complete Apple App Privacy labels and Google Play Data Safety using the actual released SDKs and data flows.
- [ ] Complete Apple export-compliance/encryption questions accurately.
- [ ] Choose the correct age rating/content declarations. If public songs, profiles or messages are user-generated content, add reporting, blocking and moderation processes as required before release.

## Store assets

- [ ] App Store icon: 1024 x 1024 PNG without alpha/transparency.
- [ ] Google Play icon: 512 x 512 PNG and feature graphic: 1024 x 500.
- [ ] Capture current, truthful product screenshots on supported device sizes. Do not include placeholders, broken links or unimplemented "coming soon" functionality.
